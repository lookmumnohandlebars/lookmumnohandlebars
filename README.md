# Look Mum, No Handlebars!

![lookmum-no-handlebars](https://github.com/user-attachments/assets/a1be8982-e3dd-4743-b494-84327c77506c)

👋 Welcome to Look Mum, No Handlebars! This is a collection of teaching resources, tutorials & open source libraries for those who want to learn programming the practical way - curated by [@alexanderthejaye](https://github.com/alexanderthejaye). Here you will find small practical repositories for creating practical applications - some of them accompany videos and courses that can be used to quickly learn how to program
